## 4. 维护方式

`workflow/plan.md` 是唯一开发计划文档，各阶段均在此更新。阶段切换时，清理前一阶段已完成的详细实施安排，将实际交付文件与验收结论整理为结果索引，再编写下一阶段的详细计划；未完成事项与未解决问题明确保留或转入后续安排。历史细节通过 Git 和日志追溯。业务变更修改对应 docs 文档，计划引用相应文件。

测试随 M2—M5 的功能同步编写、运行，M6 执行完整回归。单个测试用例组跨多个里程碑时按子例记录，不能因部分通过就标整组完成。
