# 功能与业务规则

系统提供问卷创建、分享填写、统计和管理功能；使用 Node.js + Express、原生页面和 MongoDB，在本机运行。

## 1. 账号与权限

- 支持注册、登录和退出登录；密码仅保存哈希。
- 用户名允许中英文文字、数字、下划线和连字符，长度 3—32 个 Unicode 码点，不允许空白，区分大小写。
- 密码长度 8—128 个码点，可含空格，不要求字符种类组合，不自动去除空格。
- 登录会话存入 MongoDB，通过 Cookie 标识，固定 24 小时有效，访问不续期。
- 作者仅能管理自己的问卷和查看其统计、答卷；分享链接不授予管理权限。填写前必须登录。

## 2. 问卷管理

问卷包含标题、说明、题目、匿名策略、重复填写策略和可选截止时间。

| 状态与操作 | 规则 |
| --- | --- |
| 草稿 | 可保存未完成内容，但字段类型及 ID 结构必须合法 |
| 发布 | 标题、题目、选项、限制和规则须通过完整校验 |
| 发布后编辑 | 首次发布即冻结题目、选项、限制、必答、顺序和跳转；修改需复制为新草稿 |
| 填写策略 | 匿名和重复填写策略从首次发布起固定 |
| 元信息 | 发布后可改标题、说明、截止时间；答卷展示当前标题和说明，不保存其快照 |
| 关闭与重开 | 可手动关闭，重开保留答卷与累计提交次数；重开时截止时间须为空或晚于当前时间 |
| 到期 | 不设截止时间则不自动到期；仅因到期停止接收的问卷，延期后可恢复，手动关闭仍需明确重开 |

提交按服务端事务受理时的状态和时间判断。到期或关闭后拒绝新受理，即使此前已开始填写；已受理的请求可完成保存。事务冲突回滚后的尝试重新检查受理条件。题目定义变化后，持有过时定义的页面须重新载入再填写。

## 3. 匿名与重复填写

| 匿名模式 | 行为 |
| --- | --- |
| 强制匿名 | 所有答卷均对作者匿名 |
| 允许匿名 | 填写者选择匿名或实名 |
| 禁止匿名 | 必须实名提交 |

匿名答卷保留内部账号引用以执行提交次数限制，但作者页面与 API 不返回账号关联字段。实名答卷可显示用户名。匿名范围不包含系统运营者，也不能隐藏填写者主动写在答案里的个人信息。

重复填写默认每账号每问卷仅一次，也可允许多次。匿名与实名共用账号次数；允许多次时，每次主动成功提交形成独立答卷。同次提交的双击或网络重试不重复保存。成功答卷不可由填写者修改或撤回。

## 4. 题目与校验

| 题型 | 可配置限制 |
| --- | --- |
| 单选 | 选项与必答 |
| 多选 | 选项、必答、最少/最多选择数；上下限相同表示恰好 N 项 |
| 文本 | 必答、最短/最长长度 |
| 数字 | 必答、最小/最大值、是否整数 |

非空答案必须类型正确并满足限制；可选题空答不执行内容限制。纯空白文本视为空，非空文本原样保留；长度按 Unicode 码点计算，组合表情可能计多个码点。数字 0 有效，数值须有限，整数须可安全表示，不提供精确十进制运算。

前端及时提示错误，服务端独立复核。发布时检查配置上下界、题目/选项 ID、规则引用及条件与题型的匹配。

## 5. 跳转与填写

规则按顺序使用第一条命中结果；无命中进入下一题，末题后结束。单选按选项匹配，多选支持任意包含、全部包含、集合完全相同，数字支持等于、不等于、大小比较和闭区间。目标可为任意题或结束问卷。

- 每次“下一题”只执行一次跳转，允许前进、回跳、自跳和循环，不限制访问或跳转次数。
- “上一题”沿实际访问顺序返回；修改后保留答案缓存，供再次访问时回填并重新校验。
- 到达结束页仍须确认提交。未提交进度仅在当前页面内，刷新或关闭后重新填写。
- 最终有效路径按最终答案从第一题重算，只保存路径内答案及必要路径信息；被跳过的必答题无需回答。
- 固定答案导致路径无法结束时拒绝提交，不在后台无限计算。每题最终只保存一个答案，不保存完整修改历史或提供过程回放。
- 登录过期时保留当前页面答案，恢复原账号后重试；不能自动更换填写者。

## 6. 统计与答卷

仅统计成功答卷，同账号多次合法提交分别计数，每份答卷的每题只计最终答案一次。

- 单选、多选展示选项次数及百分比，分母为该题非空有效回答数；空答和跳过不计入，多选百分比之和可以超过 100%。
- 数字展示回答及平均值，文本展示回答内容；无有效数字时平均值为 null，无有效回答时百分比为 null。
- 作者可分页查看逐题回答和完整答卷，匿名不暴露账号，实名仅显示允许的用户名。
- 关闭、到期的问卷仍可查看统计和答卷。

跨问卷统计按具体版本汇总当前用户自己的问卷，不合并不同版本或另存题。每份成功答卷分别计数，不按用户去重；选择题沿用上述分母，数字另提供数值升序分页频次，文本及其他回答的分页明细标明来源问卷。版本可并列查看，删除问卷后其回答退出统计，不保存累计副本。

题目使用情况仅列自己的引用问卷及版本，不显示他人引用数量、标题或答卷。共享题目不授予他人统计权限。

## 7. 永久删除

草稿、已关闭或已到期的自有问卷可删除，不受答卷数量限制；仍开放的问卷须先关闭。

确认框展示标题、当前答卷数及不可恢复说明，必须输入精确的“删除”并点击“永久删除”。服务端再次验证所有权、资格、修订号和确认词。

删除原子移除问卷及全部关联答卷，包含并发受理请求可能产生的结果；成功后不得留下孤立答卷。网络中断时保留“删除结果待确认”，原账号重试确认后再更新列表。

原分享链接和填写 API 统一提示“问卷不存在或已删除”。已打开的页面在再次读取或提交确认资源不存在后停止提交并清除相关授权内容，不通过轮询或推送远程抹除页面。

## 8. 独立题目与版本

可以直接创建完整合法的独立题目，或从问卷中主动保存。问卷内临时题不自动进入题目列表，不按题干文字识别同题。

独立版本固定题型、题干、选项与答案限制；必答、顺序、跳转由每份问卷配置。每次保存修改生成不可覆盖的新版本，无内容变化不生成新版。可从任意历史版本分叉，编号按创建顺序递增；恢复旧版也创建新版，记录父版本及恢复操作。选项沿用稳定 ID，删除后新增的选项使用新 ID。

另存形成接收者自己的题目和版本历史，保留来源版本，仅用于追溯，不自动合并统计；来源无权访问时不开放其详情。题目只提供归档和恢复，不物理删除。归档后停止新增选用、另存及共享，已有问卷和统计保留；恢复后原授权继续可用。

## 9. 共享、题库和问卷引用

按大小写敏感用户名共享，授权包含全部历史及后续版本。接收者可选用或另存，不可改原题、创建原题新版或转授原题。撤销后停止浏览原题、新增选用、换版及另存，不影响已有引用和独立另存题。已有问卷包含的版本内容、自己的引用情况和统计仍可查询。

每人可创建多个具名题库；一题可加入多个题库或不分类。题库可收录自有及共享题，不增加权限；原授权失效时显示不可用。删除题库仅删除分类与收录关系，不删除题目。没有整库共享。

问卷引用具体版本，独立版本更新不改变任何已有问卷。草稿可手动换版，同一版本在一份问卷中只能出现一次，不同版本可以并存。换版保留实例 ID、位置、必答及跳转，有效规则保留，失效项需修复；可存草稿，不可带失效规则发布。已关联内容不能直接篡改或解除来源；需创建自己的新版或另存后换版。

将草稿中的临时题保存为独立题目时，原子建立引用；已发布问卷只能导出题目，不修改原引用，不将旧回答追溯计入新题统计。未关联独立版本的旧题继续按原问卷统计。

复制问卷创建新草稿，复制配置及题目、重映射实例 ID 与跳转，清空截止时间，不复制答卷，新建链接。引用题目已归档或授权失效时，整体拒绝并提示不可用题目；保留旧引用不等于可以复制新增引用。
