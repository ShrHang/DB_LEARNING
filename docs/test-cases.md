# 测试说明

## 1. 运行与隔离

环境要求和数据库启动见 [README](../README.md)。

```bash
npm run db:start
npm test
npm run test:browser
```

`npm run test:unit` 可独立运行，无需数据库；`npm run test:integration` 使用真实 MongoDB 副本集和 Supertest agent。浏览器测试通过 CDP 操作本机 Chromium，无额外浏览器框架，可设置 `CHROMIUM_BIN`。

每套分配唯一 `questionnaire_test_<随机标识>` 数据库，不采用业务数据库名，结束仅清理本次资源。账号分别使用独立 Cookie agent，写入步骤为获取 CSRF→注册/登录→取得登录后 token→发送带 Cookie 和 token 的请求。

时间边界由业务时钟控制，并发由测试装配的 Promise 闸门控制；实际约束、查询、聚合及事务均使用 MongoDB。故障钩子不暴露 HTTP 入口。期望值独立计算，不调用被测函数生成期望值。

## 2. 固定样例

题目和选项别名仅用于说明，测试工厂生成合法 ID。

**路径样例**：Q1 必答文本→Q2 必答单选；Q2=A 去 Q3，Q3 选择 Back 回 Q2，Q2=B 去 Q4；Q4 必答文本后结束。实际访问 Q1→Q2(A)→Q3→Q2(B)→Q4→END，最终路径为 Q1/Q2/Q4，Q3 不保存。

**统计样例**：题目为单选 A/B/C、可选多选 X/Y/Z、可选数字、可选文本，无跳转。

| 答卷 | 单选 | 多选 | 数字 | 文本 |
| --- | --- | --- | --- | --- |
| 1 | A | X、Y | 10 | 清晰 |
| 2 | B | Y | 20 | 方便 |
| 3 | A | 空 | 空 | 空 |

预期总答卷 3；单选 A=2/B=1/C=0；多选有效回答 2，X=1/Y=2/Z=0，百分比 50%/100%/0%；数字均值 15；文本非空明细 2 条。数值 0 独立用 [0,10] 验证，均值 5。浮点百分比以误差不超过 1e-9 比较。

| 编号 | 步骤与输入 | 预期及实际输出 |
| --- | --- | --- |
| I01 | 注册 Alice/alice、重复 Alice，空格密码原样及去空格登录 | 大小写账号可并存；重复 409；密码原文验证，响应无哈希；长度边界另由单元测试验证 |
| I02 | 登录后持续访问，将时钟推进到 24h-1ms 与恰好 24h，保留会话文档 | 到期前 200、到期 401，访问不续期，TTL 未清理也失效 |
| I03 | 未登录、缺/错 CSRF、另一作者访问问卷/统计/答卷 | 401/403/404；列表仅自己的资源，拒绝不写入 |
| I04—I05 | 创建草稿，添加并重排四类题，发布不完整/完整定义；发布后改策略、首份后改题 | 创建 201、保存/发布 200；不完整发布 422；策略/冻结冲突 409；元信息仍可改 |
| I06 | 读取题目定义后作者修改，再按原版本提交 | 409 DEFINITION_CHANGED，无答卷或误冻结 |
| I07 | 三种匿名模式各提交 true/false，作者读取答卷与回答 | 非法匿名方式拒绝；匿名内部保留 ID，作者响应无身份，实名仅允许字段 |
| I08—I09 | 同账号不同请求并发；同 requestId 同内容并发/重试，再改内容 | 单次策略只保存一份；多次策略保存独立答卷；同请求同 ID 重放 200，不同内容 409 |
| I10—I11 | 首份冻结后注入故障；编辑与首份提交受控竞争 | 故障全回滚；编辑成功则原版本提交失败，或提交成功后编辑被拒绝，无混用版本 |
| I12 | 绕过页面提交缺必答、非法选项、伪造身份/路径、路径外答案及固定循环 | 非法字段 400，答案/路径 422，均无答卷；合法分支 201 且只保存有效路径 |
| I13—I14 | 截止前 1ms/恰截止、关闭后新请求、先受理再关闭；成功请求关闭/到期后重放、重开后再填 | 边界拒绝；已受理尝试可完成；回滚重试重新受理；成功重放 200；重开不恢复次数 |
| I15—I16 | 真实提交统计样例；无答卷/空值/[0,10]；同账号多份及同时间分页 | 计数、分母和均值与手算一致；空指标 null；静态分页无重复遗漏，匿名保护一致 |
| I17 | 过期提交、原页恢复原账号，另切换账号沿用 expectedUserId | 401 不写入；原账号可重试；换账号 409 ACCOUNT_CHANGED |

对应文件：[账号与会话](../tests/integration/auth.test.js)、[存储约束](../tests/integration/database.test.js)、[问卷管理](../tests/integration/surveys.test.js)、[提交](../tests/integration/submissions.test.js)、[并发](../tests/integration/concurrency.test.js)、[统计](../tests/integration/statistics.test.js)、[权限与分页](../tests/integration/statistics-access.test.js)。[初始化结构兼容](../tests/integration/schema-upgrade.test.js)与[协调记录初始化](../tests/integration/guard-upgrade.test.js)验证重复执行、数据保留及事务回滚。

关键并发时序：

1. **同请求重放**：两个独立请求同时发送同 requestId/负载，返回同 submissionId，数据库只有一份；丢弃成功响应再重试仍返回原结果。
2. **首份回滚**：冻结写入后、插入成功前注入失败，检查答卷为 0、contentLocked=false、firstSubmittedAt=null、revision 未留下冻结更新。
3. **关闭受理**：已有答卷且允许多次，暂停受理后未插入的请求，关闭问卷再释放；该尝试可成功，新受理拒绝。若事务冲突回滚，重新检查关闭状态。

## 5. 删除与页面用例

删除集成使用两个独立应用装配共享同一测试库，验证数据库协调，而非依赖进程内队列。下表预期均通过对应层的断言，浏览器单独未覆盖的分支见验证范围。

| 编号 | 步骤与输入 | 预期及实际输出 |
| --- | --- | --- |
| X01—X03 | 删除草稿、关闭/恰到期及有匿名/实名答卷的问卷；开放、越权、错确认词/账号/修订号请求 | 可删资源及关联数据移除，无关数据保留；开放 409，其余按 API 拒绝，无意外删除 |
| X04 | 重复初始化协调记录、创建中注入失败、运行时移除测试 guard | 初始化保留数据和 token；创建失败原子回滚；缺 guard 拒绝且不运行时重建 |
| X05—X06 | 受理提交分别暂停在写 guard 前/后，关闭并删除，再释放请求 | 事务竞争后删除包含已保存答卷，或提交失败，最终无问卷/答卷/guard；仅关闭不删除仍允许已受理尝试完成 |
| X07—X08 | 删除与重开、延期、编辑、重复删除竞争；清理答卷后故障；删除后原分享与提交重放 | 修订/资格一致，失败全回滚；删除后统一 404，不重建数据；仍存在且关闭/到期的成功请求可重放 |
| X09—X10 | 删除成功后丢响应、原账号重试；错词/取消/双击/换账号，空末页与 360px 页面；其他页再读资源 | 未知时保留条目，确认不存在后更新；版本变化重新确认，资源失效后清理并拒绝迟到响应 |
| M01—M05 | 创建四题型→发布→其他账号填写→作者统计；路径回跳/回填、原页登录恢复、匿名明细与分页 | 页面闭环正确，有效分支保存，身份不误切换，零值/空值准确，文本按纯文本显示 |
